# Lecture 02

Visual Programming - Java Exercises

## Exercise 01

**Question:**

Write a program that reads one number from the user, then shows a menu of the following:

1. Inch to CM
2. CM to Inch
3. Feet to Meter
4. Meter to Feet
5. Dunum to Hectare
6. Hectare to Dunum
7. Fahrenheit to Celsius
8. Celsius to Fahrenheit

**Question Type:** Unit Conversion – Menu-Based Program

**Programming Language:** Java

**IDE:** NetBeans
